# UI Lookbook

A personal lookbook of 40+ UI looks (textures, patterns, scenes, UI styles) and 29 animations to borrow for future apps. Plain HTML/CSS/JS, no build step.

- `index.html`: design gallery (LB-01 to LB-42), spec drawer, "Copy prompt"
- `animations.html`: animation gallery (AN-01 to AN-29)
- `css/`, `js/`: themes, canvas renderers, content and specs

Run locally: `python3 -m http.server` and open http://localhost:8000
